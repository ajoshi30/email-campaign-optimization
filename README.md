 Email Campaign Optimization

This project aims to analyze an email marketing campaign and optimize future campaigns using Machine Learning. The goal is to improve the **click-through rate (CTR)** by identifying what factors influence user engagement.

 Case Study Questions

1. What percentage of users opened the email and clicked the link?
2. Can we predict which users are more likely to click the link using ML?
3. By how much can we improve the CTR using the model?
4. What user segments respond differently to the campaign?

Solution Overview

- Performed data cleaning & EDA on 3 provided datasets.
- Engineered features like time of day, personalization, user activity etc.
- Built a classification model to predict if a user will click the link.
- Evaluated the model and estimated CTR lift.
- Explored performance by country, purchase history, and email version.

 Tech Stack

- Python, Pandas, Matplotlib, Seaborn
- Scikit-learn (Logistic Regression, RandomForest)
- Google Colab compatible

 How to Run

1. Upload the 3 datasets to the repo or Colab
2. Open the notebook `Email_Campaign_Analysis.ipynb`
3. Run the cells step-by-step to explore and build the model
